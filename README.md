# 🧸🐧 PenguinBear 学习风格探索

一个给小学生做的互动式学习风格测试。孩子像做性格测试一样，一题一题选答案，最后看到自己的学习画像。

**品牌**：PenguinBear English（小熊 + 小企鹅）

## 这是什么？

这个项目把学习风格评估（VARK模型：视觉/听觉/动觉/读写）做成了一个有趣、可交互的网页版测试，而不是传统的纸质问卷。

**适合谁用：**
- 英语老师给自己的学生做学情诊断
- 家长带孩子在家做，了解孩子的学习偏好
- 教育机构作为入学评估的一部分

## 怎么用

1. 打开 `penguinbear-style-quiz.html`
2. 学生点击"开始探索"
3. 一题一题选答案（共8题）
4. 看完结果 —— 可以直接打印或截图发给老师/家长

## 配套文件

| 文件 | 说明 |
|------|------|
| `penguinbear-style-quiz.html` | 互动式学习风格测试（一问一答，含结果报告） |
| `penguinbear-learning-profile-system.html` | 完整版画像系统（含教师观察清单、家长问卷、策略卡，可打印） |

## 技术栈

纯 HTML + CSS + JavaScript，单文件运行，无需任何依赖或后端。可以直接用浏览器打开，也可以部署到 GitHub Pages。
